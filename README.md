# Pocket Goat

Website staging build for Pocket Goat — books, tea, stories, culture, quiet company and kindness in Constanța.

## Stack
- Next.js App Router
- TypeScript
- CSS design system (no UI framework dependency)
- RO / EN route architecture
- Vercel-ready

## Routes
- `/ro`, `/en`
- `/:locale/space`
- `/:locale/cafe`
- `/:locale/culture`
- `/:locale/cinematic`
- `/:locale/dobrogea`
- `/:locale/community`
- `/:locale/accessibility`
- `/:locale/contact`

## Design direction
Velvet Archive foundation with Lantern & Tide atmosphere and restrained Cabinet of Quiet Curiosities details. No generic beige café, nautical kitsch, literal dark-academia imitation or cartoon goat mascot.

## Current staging scope
The build intentionally uses CSS-generated atmosphere and object studies instead of pretending final photography exists. Once the physical space and visual assets are confirmed, final photography / archival assets can replace those studies without changing the information architecture.
